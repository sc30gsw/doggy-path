# Dog Memo and Today's Memo are sent to Jev

Body Fit and the Condition Check need the Owner's free text (chronic illness, an injured paw, a diet), so the Dog Memo and Today's Memo are sent to TypeSafe's API even though they may hold health facts about the dog. TypeSafe does not train on API requests, but zero data retention is offered only on its enterprise plan, so these memos are retained by a third party. The Owner's name is never sent; the dog is described only by Breed, age, sex, weight and the memos.
