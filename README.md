## Tutorial
**犬の散歩コースを提案するアプリ**

- ユーザーは以下を入力し、情報としてこれをアプリア保存し、プロフィール設定画面から編集できる
  - ユーザー名
  - 犬の名前
  - 犬種
  - 犬の性別・年齢・体重
  - 備考（犬の性格や体調・現在抱えている病など）

- ホーム画面の「散歩をコースを作る」ボタンでコースを作成（実際には以下を入力するためのモーダルなので、文言は修正したほうが良いかも）
  - このとき、今の人間の気分をセレクトボックス（icon 付き）で選ぶことができる・また備考も入力できる（気分や天気、犬の状態（ダイエット中・最近、散歩行けてなかった）など）・目標距離・時間・開始地点
  - 入力は空でもよい
  - 「コースを作成」でコース作成
  - 開始地点については、位置情報を許可している場合、現在地で、空入力の場合、デフォルト地点から算出

- 散歩コースの提案は[Jev](https://docs.typesafe.ai/introduction)で行う
  - Agent skillsの /typesafe-aiを使用
